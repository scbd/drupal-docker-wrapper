# 0001. Record architecture decisions

We will record architecturally-significant decisions as Architecture Decision Records in
`docs/adr/`, following the format in the team's `docs-adrs` skill (ADR-FORMAT.md). Decisions are
numbered sequentially and immutable once accepted; a decision is changed by superseding it with a
new ADR, never by editing the old one. Each ADR carries a `context:` field so a decision can be
mapped to the part of the system it governs.
